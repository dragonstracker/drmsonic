drmsonic {{ .Tag }}

Live and replay OTT restreamer. Pulls DASH, HLS and Smooth Streaming manifests, decrypts CENC content, remuxes the elementary streams and republishes them as HLS with an in-memory segment store.

Quick start

  1. Open Providers and create a provider.
  2. Open Config, add a stream and paste the manifest URL.
  3. For encrypted sources, paste kid:key pairs into Keys, one per line.
  4. Press SAVE ALL, then START on the Streams page.
  5. Play from /stream/<provider>/<stream>/master.m3u8.

Stream modes

  • live — rolling window, segments expire as new ones arrive.
  • replay — fixed timeline, seekable from the start.
  • vod — static asset, no rolling window.

Running modes

  • internalremuxer — native pipeline. No external process, everything in RAM.

Output modes

  • directhls — HTTP HLS served from the panel itself.
  • udppush — MPEG-TS over UDP unicast or multicast, 7 packets per datagram.

Keys

ClearKey pairs use kid:key hex notation. 16-byte keys are AES-128. Sample encryption is AES-CTR (CENC cenc/cens); cbcs sources are rejected. The Fix IV size switch forces 16-byte IV handling for packagers that emit 8-byte IVs.

Network overrides

  • Bind — source address and interface for outbound sockets.
  • Proxy — http://, https:// or socks5://.
  • DoH — DNS-over-HTTPS resolver endpoint.
  • Network scope — which phases the override applies to: script,manifest,media.

Playlists

/playlist.m3u, /live.m3u, /event.m3u, /replay.m3u and /app1.conf expose every stream for external players.

CLI

-b, -p           bind address and port
-baseurl         public URL used in playlists
-providers       providers directory
-c               config file
-user, -password static admin credentials
-allow           comma separated no-auth admin source IPs
-noautostart     do not start autostart streams
-v               verbosity 1..3
-accesslog       log every request
-version         print version

Ship log

Reads and writes providers/*.json. Each save is atomic: temp file then rename. The panel never blocks on disk I/O during streaming.
